ck-allinone — /web/

Reserved surface for the web1 demo. Currently a stub; the bundle holds this path so downstream consumers can rely on it being served.

This surface is mounted under busybox httpd at /web/. Drop your demo content over this directory at deploy time, or wait for a future ck-allinone cut that ships real content here.

See also: / (landing + WSS self-test), /cklib/ (CK.Lib.Js bundle), /web2/ (dispatch-only demo surface), /wss/ (NATS WSS endpoint routing info).
